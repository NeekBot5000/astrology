## 2. Reddit
Only post where self-promotion is allowed, read each community's rules first, and reply to every comment the same day.

**r/AppIdeas (follow-up to the original idea post).** Title: *I built the "personalized astrology book from your birth chart" idea from this sub. Here's what I learned*
> A while ago someone here posted the idea of an app that turns your birth chart into a personalized book. It stuck with me, so I built it.
>
> What turned out to be hard:
> - **Time zones.** Old birth times need historical daylight-saving rules; some times never existed (clocks jumped forward) and some happened twice. The tool now catches those.
> - **Making AI text not generic.** Free chatbots already write vague readings. So I made a rule: every paragraph must name the exact placement it's based on ("Venus in Gemini, 12th house"), and the code rejects any paragraph that doesn't.
> - **Pricing honestly.** This category is full of surprise subscriptions, so it's one payment, no account.
>
> Here's a full sample book for a made-up person: [link]. I'd love blunt feedback: would you buy this as a gift? What would make it better?

**r/SideProject.** Title: *Built a birth-chart book generator. The trick was forcing the AI to cite its sources*
> Short version of the above. Lead with the "cites its sources" idea and the tech (Swiss Ephemeris for planet positions, AI writer with automatic citation checks, PDF rendering), link the sample, and ask what you'd change.
